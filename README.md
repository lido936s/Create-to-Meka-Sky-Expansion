# 🌌 Create to Meka: Sky Expansion - Guide d'installation

Bienvenue dans **Create to Meka: Sky Expansion** ! Ce guide vous explique pas à pas comment installer le modpack pour commencer votre aventure Skyblock technique.

---

## 🚀 Étape 1 : Télécharger un Launcher
Pour jouer facilement, nous vous conseillons d'utiliser un launcher moderne. Le plus recommandé est **Prism Launcher** (léger et open-source), mais vous pouvez aussi utiliser **CurseForge** ou **Modrinth**.

* [Télécharger Prism Launcher](https://prismlauncher.org)
* [Télécharger CurseForge](https://curseforge.com)

---

## 📥 Étape 2 : Installer le Modpack

> ⚠️ **Attention à la version de NeoForge** : il faut installer **21.1.238** (et non 2.1.238). Une mauvaise version peut empêcher le modpack de se lancer ou provoquer des crashs.

### Option A : Via Prism Launcher (Recommandé)
1. Ouvrez Prism Launcher et cliquez sur **Ajouter une instance** (en haut à gauche).
2. Choisissez l'onglet **GitHub** ou **Importer**.
3. Copiez-collez l'URL de ce dépôt : `https://github.com/lido936s/Create-to-Meka-Sky-Expansion`
4. Le launcher va automatiquement configurer la bonne version de Minecraft (1.21.1) et de NeoForge (21.1.238).
5. *(Si la liste des mods est incluse)* : Cliquez sur **Télécharger les mods manquants** si le launcher vous le demande.

### Option B : Installation Manuelle (CurseForge / Autre)
1. Créez un profil personnalisé sur votre launcher en sélectionnant :
   * **Version de Minecraft :** 1.21.1
   * **Chargeur de mods :** NeoForge
   * **Version de NeoForge :** **21.1.238** *(attention : 21.1.238, pas 2.1.238)*
2. Téléchargez ce code GitHub en cliquant sur le bouton vert **Code > Download ZIP** en haut de cette page.
3. Extrayez le contenu du ZIP.
4. Faites un clic droit sur votre profil dans votre launcher, cliquez sur **Ouvrir le dossier** (*Open Folder*).
5. Glissez-y les dossiers `config`, `defaultconfigs`, `kubejs`, `schematics` et `mods` que vous venez de télécharger.

---

## ⚙️ Étape 3 : Configuration recommandée avant de lancer
Pour éviter les ralentissements ou les crashs dus aux mods techniques (Create & Mekanism) :

* **Mémoire RAM :** Allouez un **minimum de 6 Go** de RAM (8 Go recommandés) dans les paramètres de votre launcher.
* **Java :** Assurez-vous que votre launcher utilise bien **Java 21** (requis pour Minecraft 1.21.1).

---

## 🐛 Un bug ou un crash ?
Si le jeu plante ou qu'une recette est cassée, merci d'ouvrir un ticket dans l'onglet [Issues](https://github.com/lido936s/Create-to-Meka-Sky-Expansion/issues) de ce GitHub en décrivant le problème et en fournissant votre fichier de crash (`crash-reports/`).
